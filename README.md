# ENVOL

Appli de l'équipe de basket EN.V.O.L (PLC/ESG) : matchs, présences et convocations, covoiturage, effectif, photos, événements, cycles d'entraînement, messages et règles du jeu.

- Hébergement : GitHub Pages
- Données partagées : Firebase (Firestore + connexion anonyme)
- Accès : code équipe demandé une seule fois au premier lancement

## Installer sur un téléphone
- **Android (Chrome)** : ouvrir le lien, menu ⋮ → « Ajouter à l'écran d'accueil ».
- **iPhone (Safari)** : ouvrir le lien, bouton Partager → « Sur l'écran d'accueil ».
